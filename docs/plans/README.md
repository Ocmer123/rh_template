# Implementation plans

A plan breaks work that spans more than one PR into ordered, testable steps. Write one with `/plan` or by copying [template.md](template.md) to `NNNN-short-title.md`.

- Tick the checkboxes as the steps land, in the same PR.
- Set `Status: Done` when the last step merges.
- Run `python tool/docs_index.py` after adding a plan.
